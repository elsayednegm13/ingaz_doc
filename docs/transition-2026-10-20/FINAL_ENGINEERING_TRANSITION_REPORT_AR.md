## 20) آلة حالة الـIdempotency (ملخّص)

```
Origin → جلسة → حساب نشط → بوابة كلمة المرور → (مفتاح؟ مُستثنى؟)
  → claim ذرّي (UNIQUE(actor_id,key))
     ├─ MISMATCH  → 422
     ├─ IN_PROGRESS → 409
     ├─ UNKNOWN → 409 (لا تنفيذ)
     └─ NEW → المعالج → (4xx يُخزَّن) | (5xx ⇒ UNKNOWN) | (نجاح ⇒ تخزين الرد)
  → إعادة التشغيل تُعيد الرد المخزَّن **قبل** فحص الصلاحيات
```
