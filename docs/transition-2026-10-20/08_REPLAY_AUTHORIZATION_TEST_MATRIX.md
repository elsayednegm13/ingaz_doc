# 08 — مصفوفة تفويض إعادة التشغيل (Replay Authorization Test Matrix)

**التدقيق:** ET-2026-10-20
**الأدلة:** `evidence/runtime-probes.json` (الدفعة 1، 31 مقياسًا)، `evidence/runtime-probes-2.json` (الدفعة 2، 7 مقاييس)

## 8.2 تحفّظات على قوة البرهان (مُصرَّحة)

| القياس | التحفّظ |
|---|---|
| IDEM-P | الطلبات **مُسلسلة** بسبب تبريد 350ms في عميل الفحص (نفس علة workerd المحلية). المسار المُختبَر هو **إعادة التشغيل** لا سباق claim حقيقي. سباق 15 طلبًا متزامنًا **بدون** تبريد مُثبت في `e2e/duplicates.spec.ts` (DUP-C) أثناء الجولة السابقة ⇒ `PRIOR_REPORT` + `OBSERVED_TEST` سابق. |
| IDEM-E | لا مسار API لإعادة الإسناد (بحث `server/http/app.ts`) ⇒ الحالة غير قابلة للإنتاج عبر الواجهة العامة اليوم. |
| IDEM-F / IDEM-G | الفشل **مُثبت بمقياس** (صفّان لنفس العملية) لا بقراءة شيفرة فقط. |
| IDEM-H | عطل مُحقَن عبر ترويسة اختبار موجودة في شيفرة الإنتاج (`x-test-fail-before-handler`)، وهو **عطل محاكاة** لا إيقاف حقيقي للـWorker. |
| IDEM-Ib | أُعيدت صياغة حجز المنتهية الصلاحية **بتعديل `updated_at` في قاعدة التدقيق** (لاTiming طبيعي). |

## 8.3 مصفوفة التفاعل بين التفويض وإعادة التشغيل (تحليل)

| الحالة | المفتاح باقٍ؟ | الفاعل ما زال مخوَّلًا؟ | إعادة التشغيل | الحكم |
|---|---|---|---|---|
| لا تغيير | نعم | نعم | تُعيد الرد المخزَّن | متوقّع |
| تغيير الدور | **لا (محذوف)** | لا | 403 | آمن — لكن بتدمير الدليل |
| تغيير الدور إلى دور أرقى | **لا (محذوف)** | نعم | **أثر ثانٍ** | **خطر (IDEM-F)** |
| تغيير تجاوز صلاحية | **لا (محذوف)** | نعم غالبًا | **أثر ثانٍ** | **خطر (IDEM-F)** |
| تعطيل الحساب | لا (تُحذف الجلسات والمفاتيح) | لا | 401 | آمن |
| انتهاء صلاحية المفتاح | يُحذف تلقائيًا | نعم | **أثر ثانٍ** | **خطر مقيَّد (IDEM-G)** |
| إعادة إسناد الطلب | يبقى | خارج النطاق | **يُعاد الرد** | **خطر كامن (غير قابل للوصول اليوم)** |

## 8.4 الخلاصة

| البند | الحكم |
|---|---|
| نواة الـIdempotency (تطابق، تفرد، التزامن، UNKNOWN) | **PASS** بمقاييس معزولة |
| تفويض إعادة التشغيل | **PARTIAL**: محمي بالحذف المدمر، وليس بإعادة التفويض؛ فيه مساران مثبتان لتكرار الأثر (IDEM-F، IDEM-G) |
| عمر المفتاح | **محدود بساعة** — لا يُadvertise كضمان «مرة واحدة مدى الحياة» |
| الخصوصية | جسد الرد المخزَّن بيانات أعمال ⇒ أي مسار allows إعادة تشغيل بلا تفويض = تسريب |
