## 4. أول بوابة هندسية يجب استكمالها الآن

**البوابة الأولى هي M01 — إغلاق P0 للعزل ثم قبول بيئة تشغيل محلية مصطنعة.**  
هذه البوابة هي precondition لكل بوابة تالية (M02، M03، M04، M05، M10، M11، M12). بدون إثبات أن أدوات التشغيل والاختبار تبقى داخل جذر مؤقت معزول ولا تلمس `.wrangler/state` أو الجذور التاريخية في كل مراحل حياة العملية (البداية، التشغيل، الخطأ، الإغلاق، التفكيك)، لا يمكن المضي إلى أي اختبار runtime أو ترحيل أو E2E.

**لماذا هذه البوابة أولاً؟**
- AGANT.MD وHANDOFF.MD وغيرهما تمنع بدء Wrangler/Vite/Playwright حتى يُثبت العزل.
- HANDOFF.MD القسم 06.2 يشترط إثبات العزل قبل أي تشغيل runtime.
- إصلاحات M02 (P1) تعتمد على بيئة تشغيل معزولة ليتم اختبارها على D1 حقيقي.
- M03 (BR v1.0) هو توثيق تجاري ويمكن متابعته بالتوازي، لكنه لا يخول كوداً جديداً.

### 5.2 предпrequisites (قبل أي أمر runtime)
1. إذن المالك الصريح لهذا النطاق تحديداً (M01 فقط، لا تطوير ميزات جديدة).

3. مراجعة 읽ة فقط لكل سكريبت تشغيل (`vite.config.ts`، `scripts/e2e-server.mjs`، `playwright.config.ts`، `shared/isolation.ts`، `scripts/isolation-guard.mjs`، `e2e/helpers.ts`، `e2e/setup.spec.ts`).
4. إنشاء جذر مؤقت فريد باسم `.wrangler-safety-20261021-<run-id>` تحت جذر المشروع (ليس تحت `.wrangler/state`).

## 6. معايير GO/NO-GO قبل الانتقال إلى المرحلة التالية (M02)

| المعيار | حالة GO | حالة NO-GO |
|---|---|---|
| العزل الثابت (source) | كل سكريبت تشغيل يربط persist بجذر مؤقت معزول، geen افتراضي إلى `.wrangler/state` | أي مسار افتراضي إلى `.wrangler/state` أو جذور تاريخية |
| العزل التشغيلي (runtime) | تشغيل تجريبي ناجح في root مؤقت جديد، geen لمس لملفات محمية، geen كاتب خارجي غير مبرر | لم يُثبت runtime، أو وُجد وصول غير مصرح |
| اختبارات الحارس | رفض كل المسارات المحمية (صناعية) | أي مسار محمي يُقبل |
| Metadata المسارات المحمية | geen تغيير غير مبرر قبل/بعد | أي تغيير غير مبرر في `.wrangler/state` أو جذور تاريخية |
| الأسرار | geen أسرار حقيقية في أي تقرير أو كود | أي سر حقيقي مُعلَن |
| موافقة المالك | إذن صريح لمدى M01 فقط | geen إذن |

**القرار النهائي لمخارج M01:** `GO` فقط إذا استوفى كل المعيار أعلاه. أي `NO-GO` في معيار واحد يتوقف عنده العمل ويُبلغ المالك.
